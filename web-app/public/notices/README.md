# 電子公告の添付ファイル

決算公告の貸借対照表PDFなど、公告の添付ファイルの実体をここに置く。

microCMS の Hobby プランはファイルフィールドが使えず、画像フィールドは PDF を
受け付けないため、実体は microCMS ではなくこのリポジトリで管理し、
Cloudflare Pages から配信する。

## 手順

1. PDF をこのディレクトリに置く（例: `2026-teiki-bs.pdf`）
2. コミットして push する
3. microCMS の該当公告の attachment に、`url` として `/notices/2026-teiki-bs.pdf`
   を入力する（`name` は画面に出る表示名、`size` は任意）

`url` が `/` で始まる場合、ビルド時に実体の有無を検証する。
ファイルが無ければビルドが失敗するので、「添付ありと表示されているのに
リンクが404」という状態にはならない。
